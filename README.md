
## Modèle de rapport PatriNat (non officiel)

Ceci est un modèle de rapport PatriNat au format `Rmarkdown` qui intègre notamment : 

- la police Marianne dans le texte ainsi que dans les graphiques s'ils sont produits dans un *chunk* du document.
- les pages de couverture et la quatrième de couverture (optionnelle), 
- la mise en forme selon le style préconisé (table des matières, légendes des tableaux et figures ...).

Les pages de couverture et la quatrième de couverture localisées dans le sous-dossier "couverture" sont à modifier au format `word` puis à enregistrer sous `pdf`.
